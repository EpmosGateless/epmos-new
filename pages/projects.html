EXPLANATION

Standard public profile

Each profile identifies purpose, public status, maturity, current capabilities, evidence, known limitations, and public documentation where available.

Status discipline

CONCEPT, RESEARCH, PLANNING, LIVING, WORKING, VALIDATION, MASTER, EXPERIMENTAL, PUBLIC DEMONSTRATION, ARCHIVED, and SUPERSEDED are not interchangeable labels. A visual treatment must never imply a higher maturity level than the evidence supports.

Disclosure boundary

This portal explains public-safe principles, goals, behavioral standards, evidence posture, and documented status. It does not publish protected formulas, private prompts, controlled source code, credentials, security topology, exploit details, or material that would enable reconstruction of protected invention architecture.
