# PLANNING — EPMOS Public Information Portal

**Date:** 2026-08-26 EDT  
**Lifecycle:** PLANNING

## First public release

The first release extends the restored homepage into a static, multi-page portal with pages for What is EPMOS, Principles, How Governed AI Works, GATELESS, Evidence & Testing, Research, Products & Projects, Knowledge Center, About, and Contact & Engagement.

## Content model

Pages use reusable public-safe patterns: page hero with visible status, conceptual flows, information cards, project profiles, principle lists, status tables, glossary terms, FAQ disclosures, explanation sections, and a disclosure-boundary note. The content model is intentionally static and reviewable now while remaining easy to extend with future documents, projects, research notes, and validation records.

## Navigation and discovery

The shared primary navigation links all first-release pages. `sitemap.xml`, `robots.txt`, semantic headings, page titles, descriptions, canonical metadata, Open Graph metadata, and a branded `404.html` establish the searchability and fallback foundation. Site-wide search is left in PLANNING until a stable document model and approved corpus exist.

## Safety constraints

All content is limited to public-safe principles, behavioral standards, documented status, conceptual educational diagrams, and explicit evidence limits. Protected invention architecture, formulas, prompts, credentials, security topology, exploit details, and reconstruction-enabling material remain outside the site.

## Implementation sequence

1. Preserve the known-good homepage baseline.
2. Add shared navigation, stylesheet, and accessible mobile menu behavior.
3. Add high-value educational and status pages.
4. Add SEO and 404 foundations.
5. Verify links, assets, responsive layouts, accessibility basics, and console behavior.
6. Keep the resulting work in WORKING / LIVING state for Founder review; do not promote to MASTER.
